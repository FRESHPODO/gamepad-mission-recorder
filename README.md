# 게임패드 동선 기록실

## Switch 2 프로콘 USB 연결

Chrome에서 localhost 또는 HTTPS로 페이지를 열고 상단의 **Switch 2 USB 연결**을 눌러 장치를 선택합니다. 웹이 USB 초기화, 입력 형식 선택, HID 출력 활성화를 수행합니다. 완료 후 A 버튼을 눌러 게임패드 감지를 확인하세요. 외부 사이트나 프로그램 설치는 필요하지 않습니다. 브라우저의 장치 선택은 사용자가 직접 해야 합니다.

실패하면 버튼 아래에 실패 단계와 오류가 표시됩니다. ‘게임패드 입력 진단’을 펼치면 장치 ID, 매핑, 축과 버튼 값을 확인할 수 있습니다. 인터페이스 확보 실패 시 Steam이나 다른 패드 도구를 종료하고 USB를 다시 연결하세요. USB 초기화에 성공해도 Chrome이 장치를 Gamepad API로 제공하지 않으면 조작할 수 없습니다. 실제 Switch 2 하드웨어 동작은 아직 검증되지 않았습니다. Windows Chrome의 비표준 Switch 2 입력은 HID Rx/Rz에 해당하는 RS 축 3·5와 ZR 버튼 5를 사용합니다. 표준 매핑은 RS 축 2·3과 RT 버튼 7을 사용합니다. Switch 2 비표준 입력의 Y 부호는 화면 좌표에 맞게 반전하며 녹화 rawY에도 동일한 Y 부호 반전을 적용합니다. rawX/rawY는 패드 방향 통일 후, 원점 및 데드존 처리 전 값입니다. 사용자 보정은 적용하지 않습니다.

초기화 프로토콜 출처: https://github.com/ndeadly/switch2_controller_research/blob/master/commands.md


`index.html`을 브라우저에서 열면 실행됩니다. 게임패드 API 사용을 위해 Chrome/Edge에서 localhost로 실행하는 방식을 권장합니다. Python이 설치되어 있다면 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다.

표준 매핑 게임패드의 오른쪽 스틱(axes 2, 3)과 RT(button 7)를 사용합니다. 방향키와 Enter로 대체 조작할 수 있습니다. 첫 이동 미션은 RT로 시작합니다. 이동 미션은 RT로 제출하며 다음 이동 미션은 자동으로 시작합니다. 막대 회피 미션은 RT로 시작합니다. 축 회피 미션은 RT로 시작하고 막대 10개가 지나가면 결과를 자동 저장한 뒤 다음 미션으로 넘어갑니다. 다음 회피 미션은 RT를 다시 눌러 시작합니다. 각 미션은 화면 중앙 원점에서 시작합니다. 이동 미션은 안내 경로 순서와 도착 여부로 성공을 판단합니다. 회피 미션은 지정된 축으로만 이동하며 실시간 화면과 리플레이에서 이동 동선을 표시하지 않습니다. 오브젝트 최대 속도는 초당 400px입니다. 지그재그 경로는 중앙에서 오른쪽으로만 이어집니다.


경로 오차율은 각 기록 위치와 기준 경로 사이 최소 거리의 평균을 화면 대각선 길이로 정규화한 백분율입니다. 회피 오차율은 충돌한 막대 수/10의 백분율입니다. 막대 틈은 무작위로 생성되고 JSON에 저장됩니다. 리플레이는 저장된 위치와 막대 정보를 재현합니다.

## 웹 미션용 가상 게임패드

가상 게임패드의 **웹 미션에 사용**을 켜세요. RS 원 안을 클릭하거나 누른 채 드래그하면 방향과 세기가 입력됩니다. 놓으면 중앙(0, 0)으로 돌아옵니다. RT는 기본 **Space(스페이스)** 키이며 E, Q, Enter, 오른쪽 Shift로 변경할 수 있습니다. 키를 누를 때 미션 시작 / 이동 미션 제출을 수행합니다. 회피 미션은 기존처럼 자동 완료됩니다.

가상 모드를 끄면 기존 실제 게임패드와 방향키 / Enter 조작을 사용할 수 있습니다. 가상 입력은 JSON 표본의 virtualGamepad와 rt에 저장됩니다. Windows에 컨트롤러 장치를 등록하는 기능은 포함하지 않습니다.

## 미션 전 감도 연습

페이지를 열거나 전체 초기화하면 감도 연습 모드가 시작됩니다. 실제 패드 RS, 가상 RS 또는 방향키로 화면 전체를 자유롭게 움직일 수 있습니다. 이동 속도와 스틱 입력은 실제 미션과 동일하며 연습 시간과 입력은 기록되지 않습니다. RT(가상 패드 기본 Space)를 누르면 원점에서 선택한 미션이 시작됩니다.

## 리플레이 페이지

전체 미션 녹화가 완료되면 결과 다운로드 버튼이 표시됩니다. 녹화 기록 영역에서도 JSON 다운로드가 가능합니다. 리플레이 페이지 이동은 우상단 링크에서 제공하며 현재 녹화 기록을 전달합니다. 저장한 JSON은 리플레이 페이지에서 불러옵니다. 페이지 간 기록 전달은 같은 브라우저와 주소에서 작동하며, localhost 실행을 권장합니다.

리플레이는 저장된 위치, 막대 상태, RS 원시 입력 및 적용 입력, RT 값과 입력 장치를 함께 표시합니다. 새 기록은 실제 패드·가상 패드·키보드의 RT를 모두 저장합니다. 이전 JSON에 RT 정보가 없으면 기록 없음으로 표시합니다.

단축키: Space 재생/정지, Q 이전 프레임, W 다음 프레임. 텍스트 입력과 선택 목록에 포커스가 있을 때는 단축키를 처리하지 않습니다. 녹화 화면의 가상 RT 기본 키는 기존 Space입니다.

## 모바일 조작

모바일 또는 작은 화면에서는 가상 패드가 자동 활성화됩니다. 위쪽에는 미션 화면이 표시되고, 아래쪽에 고정된 RS 스틱과 RT 터치 버튼이 표시됩니다. RS를 누른 채 다른 손가락으로 RT를 눌러 시작하거나 제출할 수 있습니다. 스틱을 놓으면 중앙으로 돌아오며, 화면을 벗어나거나 터치가 취소되면 입력이 해제됩니다. 데스크톱에서는 기존 우측 패널과 키보드 조작을 사용할 수 있습니다.


실제 패드의 RS를 놓고 **현재 RS 입력을 원점으로 설정** 버튼을 누르면 현재 입력값을 원점으로 저장합니다. 이후 적용 입력에서 해당 값을 빼고 Switch 2의 Y 방향을 반전합니다. 기록의 rawX/rawY는 패드 방향 통일 후 값이며, 원점을 뺀 입력에 기본 0.02의 원형 데드존을 적용합니다. 데드존은 화면의 숫자 입력으로 0~1 사이에서 조절할 수 있고, 데드존 밖의 크기는 그대로 유지합니다. 원점은 패드 ID별로 현재 페이지에서만 유지되고 새로고침하면 0으로 돌아갑니다. 가상 패드와 키보드에는 적용하지 않습니다.

Switch 2 비표준 프로콘의 새 녹화는 rawY와 inputY 모두 화면 기준 상하 방향을 사용합니다. 기존 녹화 파일은 변경하지 않습니다.

새 기록은 미션의 시작 원점과 매 표본의 stickOrigin(x,y), deadzone을 저장합니다. 원점 좌표는 rawX/rawY와 같은 방향 기준이며 Switch 2 Y 반전도 동일하게 적용합니다.  리플레이의 RS 표시는 rawX/rawY에서 해당 표본의 원점을 뺀 값입니다(미션 축 제한·데드존 처리 전). 녹화 중 원점을 바꿔도 각 표본의 원점을 재현합니다. 원점 정보가 없는 이전 기록은 (0,0)을 사용합니다.

다운로드 파일명은 패드 종류_YYYYMMDD_HHMMSS.json  형식입니다(예: physical_20261006_143000.json). 시간은 세션 생성 시각의 한국 시간이며  실제 패드와 가상 패드가 섞인 기록은 virtual+physical로 표시하며 키보드 입력은 keyboard로 표시합니다.

결과 다운로드는 입력 표본, 원점 좌표, 위치 및 막대 상태를 포함하는 JSON 파일이며 리플레이 페이지에서 불러올 수 있습니다.
