기록 불러오기

기록은 이 브라우저에서 분석합니다. JSON을 서버로 전송하지 않습니다. 같은 브라우저의 최근 수집 기록은 자동으로 불러옵니다.

동일 조건 합산

참가자·장치·제어 모드·과제·A/W·화면 크기·DPR·컨트롤러·스틱/데드존/속도/반지름 배율·선택 정책별로 구분합니다. MT·We·TP는 합산한 시행으로 재계산합니다. TP는 5회 이상이며 We와 Ae가 양수일 때 표시합니다.

JSON을 불러오면 결과가 표시됩니다.

Fitts 회귀 · MT = a + b × ID

A/W를 제외한 나머지 조건이 같은 기록의 조건별 평균 MT로 비가중 선형 회귀를 계산합니다. 서로 다른 ID가 3개 이상 필요합니다. a와 b의 단위는 ms, ms/bit이며 1/b는 TP로 표시하지 않습니다.

지표 정의와 분석 범위

MT: 선택 간 시간. ER: 타깃 밖 선택 비율. 선택 편향: 중심 대비 이동 축 방향(축) 및 수직 방향(횡) 선택 오차의 평균. 선택 오차: 타깃 중심까지 거리의 평균.

We = 4.133 × 선택 축 오차의 표본 SD. Ae는 실제 선택 시작/종료점의 축 투영 거리 평균. TP = log₂(Ae/We+1) ÷ 평균 MT(s). 오선택을 포함합니다.

TRE: 타깃을 나갔다 다시 들어온 횟수. MDC / ODC: 횡방향 / 이동 축 방향 전환 횟수 (원문 도식의 MDC / ODC). TAC: 이동 축 교차 횟수. MV: 경로의 횡방향 좌표 표본 SD. ME / MO: 횡방향 절대 오차 / 부호 있는 오차 평균. 효율: 실제 선택 시작–종료 직선거리 ÷ 경로 길이.

동선 지표는 시행별 계산 후 평균합니다. 방향 전환·교차에는 0.5 CSS px 임계값을 적용합니다. 시작/종료 선택점과 중간 표본이 필요하며 최대 간격이 설정값을 넘으면 제외합니다. 이 간격과 최소 표본 기준은 앱의 분석 기준으로 ISO 요구사항이 아닙니다. 프레임 표본 사이의 빠른 재진입·방향 전환은 감지되지 않을 수 있습니다. 표본 누락을 다른 파일로 복원하지 않습니다.

중단 세션은 기본 제외하고 완전히 같은 세션의 중복 입력은 한 번만 집계합니다. 이전 녹화의 첫 시행은 시작 선택 좌표가 없으면 동선 분석에서 제외합니다. 구버전 스틱값이 화면 좌표로 저장된 동선은 제외합니다. 현재 참가자·장치 ID만으로 OS 포인터 감도나 물리 화면 크기의 동일성을 보장할 수 없으므로 실험 조건을 별도로 통제하세요. 학습·피로·순서 효과와 유의성 검정은 자동 평가하지 않습니다.

참고: MacKenzie, Kauppinen & Silfverberg (2001), CHI, 9–16 · Soukoreff & MacKenzie (2004), IJHCS, 61, 751–789.
